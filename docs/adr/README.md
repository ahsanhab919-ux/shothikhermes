# Architecture Decision Records

This folder contains the foundational ADRs for evolving `shothik-web` into an artifact-first AI workspace with Hermes as the orchestration layer.

## Index

- `ADR-001` - Run, Artifact, And Event Contract
- `ADR-002` - Hermes Modular-Monolith Boundaries
- `ADR-003` - API Gateway To Hermes Integration Rules
- `ADR-004` - Product Plane And Ops Plane Separation
- `ADR-005` - Capability Registry And Model Router Contracts

## Usage

These ADRs should be treated as binding architectural decisions unless explicitly superseded by a newer ADR.

When a major technical decision changes:

1. create a new ADR instead of silently rewriting history
2. reference the ADR being superseded
3. update the related product and architecture docs
