================================================================================
DOMAIN 2: COMPLETE API SURFACE OF THE PRESENTON FASTAPI BACKEND
================================================================================
Implementation-grade reference for every HTTP endpoint, schema, auth mechanism,
and external integration exposed by servers/fastapi.

--------------------------------------------------------------------------------
0. TOPOLOGY
--------------------------------------------------------------------------------

Entry point:  servers/fastapi/api/main.py
- FastAPI app `app` with lifespan `app_lifespan`.
- Routers mounted at root (each router carries its own prefix):
    API_V1_PPT_ROUTER        prefix=/api/v1/ppt
    API_V1_WEBHOOK_ROUTER    prefix=/api/v1/webhook
    API_V1_MOCK_ROUTER       prefix=/api/v1/mock
    API_V1_AUTH_ROUTER       prefix=/api/v1/auth
    API_V1_ASYNC_TASKS_ROUTER prefix=/api/v1/async-tasks
- Static mounts:
    /app_data  -> StaticFiles(directory=<APP_DATA_DIR>)  (images, fonts, exports, pptx-to-html)
    /static    -> StaticFiles(directory=<resource>/static) (icons, etc.)
- Middleware stack (outermost first):
    CORSMiddleware (allow_origins=[NEXT_PUBLIC_URL] or ["*"]; allow_credentials=True)
    UserConfigEnvUpdateMiddleware  (refreshes process env from userConfig.json each request)
    SessionAuthMiddleware          (enforces session/basic auth on /api/*, /app_data/*, /docs)
    static_icon_fallback_middleware (http)  (serves icon fallbacks)

All PPT sub-routers share prefix /api/v1/ppt; each adds its own sub-prefix.

1. AUTHENTICATION
--------------------------------------------------------------------------------

1.1  Auth middleware (api/middlewares.py -> SessionAuthMiddleware)
- Skipped entirely when env DISABLE_AUTH=true (returns "electron" user).
- Paths requiring auth:
    - All /api/* paths except /api/v1/auth/*
    - All /app_data/* except public prefixes:
        /app_data/images/, /app_data/fonts/, /app_data/pptx-to-html/
    - /docs, /openapi.json, /redoc
- Accepts, in order of preference:
    (a) Session cookie `presenton_session` (validated as a signed token).
    (b) Authorization: Bearer <token> header.
    (c) Authorization: Basic <base64(user:pass)> header (verified against
        PBKDF2 hash stored in userConfig.json).
- If no credentials configured yet, returns 428 with setup_required=true.

1.2  Session tokens (utils/simple_auth.py)
- Token format:  base64url(payload_json) + "." + base64url(hmac_sha256_sig)
- Payload: {"v":1, "u":<username>, "iat":<unix>, "exp":<unix+30d>}
- Signing secret: AUTH_SECRET_KEY in userConfig.json (auto-generated, 32 random bytes).
- TTL: 30 days (SESSION_TTL_SECONDS = 60*60*24*30).
- Cookie attributes: HttpOnly, SameSite=Lax, Secure when HTTPS, Path=/, max_age=30d.
- Password storage: pbkdf2_sha256 with 200,000 iterations, 16-byte random salt.
- Internal service-to-service headers via get_internal_auth_headers(): mints a
  bearer token for the configured user (used by headless browser export).

1.3  Codex OAuth (utils/oauth/openai_codex.py + utils/oauth/pkce.py)
- Provider: OpenAI / ChatGPT (used for the "codex" LLM provider).
- Authorization server: https://auth.openai.com/oauth/authorize
- Token server:        https://auth.openai.com/oauth/token
- Client ID:           app_EMoamEEZ73f0CkXaXp7hrann
- Redirect URI:        http://localhost:1455/auth/callback
- Scopes:              openid profile email offline_access
- PKCE:                S256, 32-byte verifier.
- Local callback: HTTPServer bound to 0.0.0.0:1455 in daemon thread.
- Token exchange: httpx POST form with grant_type=authorization_code.
- Refresh: httpx POST form with grant_type=refresh_token.
- Token persistence: env vars + userConfig.json.

2. ENDPOINTS — /api/v1/auth
--------------------------------------------------------------------------------

2.1  GET /api/v1/auth/status
  Response: {configured: bool, authenticated: bool, username: str|null}

2.2  GET /api/v1/auth/verify
  Response: {authenticated: bool, username: str}
  Errors: 401 if not configured or unauthenticated.

2.3  POST /api/v1/auth/setup
  Body: AuthCredentialsRequest {username: str (3..128), password: str (6..256)}
  Response: {configured: true, authenticated: false, username: str}
  Errors: 409 if already configured; 400 on validation failure.

2.4  POST /api/v1/auth/login
  Body: AuthCredentialsRequest {username, password}
  Response: {configured: true, authenticated: true, username: str,
             access_token: str, token_type: "bearer"}
  Sets cookie: presenton_session=<token>
  Errors: 428 if not configured; 401 if credentials invalid.

2.5  POST /api/v1/auth/logout
  Response: {success: true}
  Clears cookie: presenton_session.

--------------------------------------------------------------------------------

- /api/v1/auth/*:                    EXEMPT from SessionAuthMiddleware.
- /api/v1/async-tasks/*:             Session OR Basic auth required.
- /api/v1/webhook/*:                 Session OR Basic auth required.
- /api/v1/mock/*:                    Session OR Basic auth required.
- /api/v1/ppt/*:                     Session OR Basic auth required.
- /app_data/images/, /fonts/, /pptx-to-html/: PUBLIC.
- /app_data/{exports,...}:           Session OR Basic auth required.
- /docs, /openapi.json, /redoc:      Session OR Basic auth required.
- DISABLE_AUTH=true:                 All auth bypassed; user="electron".

Codex OAuth (/api/v1/ppt/codex/auth/*) is protected by session auth but
manages a SEPARATE OAuth flow with OpenAI for Codex LLM credentials.
